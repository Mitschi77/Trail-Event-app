# Anfrage an UTMB: autorisierte MyUTMB-Datenanbindung

**Einreichung:** https://utmb.world/contact  
**Passende Themen im Kontaktformular:** „My UTMB / Running Stones“ oder „UTMB Index“  
**Alternative Datenschutzanfrage:** dpo@utmb.world (nur für Datenschutzrechte, nicht als allgemeiner API-Support)

## Nachricht (Englisch)

Subject: Request for an authorized MyUTMB integration for a personal running application

Hello UTMB team,

I am developing NORTHBOUND, a personal endurance event planning application. I would like to connect my own MyUTMB account to the app, with my explicit consent, in order to display and keep my own UTMB Index, UTMB Scores, Running Stones and race results up to date.

Could you please let me know whether UTMB provides any officially supported option for this use case, such as:

- a documented read-only API;
- an approved OAuth 2.0 / OpenID Connect client integration;
- an official data export that can be imported by a third-party personal application; or
- another recommended method for accessing my own account data.

If an integration is possible, please share the technical documentation, registration or approval process, permitted data fields/scopes, rate limits, data reuse conditions, and revocation requirements.

NORTHBOUND will not collect or store a MyUTMB password. Authentication would take place only on a UTMB-controlled page if an official authorization flow is available. The app would access only the data explicitly permitted by UTMB and selected by the account owner.

If this request should be handled by another department, I would appreciate it if you could forward it or provide the appropriate technical contact.

Thank you for your help.

Kind regards,
NORTHBOUND

ich entwickle mit NORTHBOUND eine persönliche Ausdauer- und Eventplanungs-App. Ich möchte mein eigenes MyUTMB-Konto mit ausdrücklicher Zustimmung anbinden, um meinen UTMB Index, meine UTMB Scores, Running Stones und Rennergebnisse aktuell in der App anzeigen zu können.

Vielen Dank für Ihre Unterstützung.

NORTHBOUND
